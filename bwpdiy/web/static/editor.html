BWPDIY 使用说明

基本流程

左栏新建项目与卡牌（默认新建式神；非式神卡的「所属式神」可关联同项目式神）→ 右栏编辑卡牌内容、上传卡图 → 中央实时预览 → 「保存」写盘。卡图按 id（留空则按卡名）命名落盘。连续 2 小时无操作时程序会自动停止（防占用），重新启动即可。

描述文本自适应

描述自动换行、每行水平居中、整体竖直居中；排不下时先微调居中点、再自动逐级缩小字号；遇左下/右下角标自动避让，文字不会压到数值。

关键字高亮

描述中用双英文方括号 [[关键字]] 标记，显示为牌框对应的异色（括号本身不绘制）；从左往右匹配，未配对的括号与单个 [ ] 一样按普通文本显示。

内嵌小图标

描述中输入 #xx（两位拼音首字母代码）插入行内小图标，与相邻文字间自动留四分之一宽空格；图标大小随字号缩放（布局设置中可调相对大小）。可用代码：
#ll 力量#sm 生命#hj 护甲#pj 破甲
#nl 能量#nj 耐久#zl 战力#fl 乏力
#hl 红莲#cy 苍叶#ql 青岚#zy 紫岩

卡图定位

上传卡图后可调偏移 X/Y（正值=图像右/下移）、缩放、旋转（正角度=顺时针）。平出画面的区域会留透明，可放大缩放避免露底。改动需「保存」后写盘。

框品

支持常规/琉璃/墨染/百炼四种牌框配色（协战仅常规），文字与稀有度配色随框品自动切换。

扩展选项

顶栏「扩展选项」可自行启用：手动调整布局——开放「布局设置」页，按卡牌类型微调各元素位置/字号/文本区（保存时样式类改动跨类型同步）；标记扩展——稀有度下拉开放 N；等级旁开放勾玉六色（黄/青/紫/红/蓝/棕）；式神开放可选等级与派系样式（1-3，默认 2）；各数值旁开放变色（白=常态/红=debuff或受伤/绿=buff/紫=中毒，正负号跟随变色）。取消勾选只隐藏控件，已写入卡牌的颜色/样式不回退。
