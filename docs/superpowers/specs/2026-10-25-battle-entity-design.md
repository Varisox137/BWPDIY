# 对局式神小卡渲染设计（v1.7.0）

## 目标与边界

为「式神」「形态」及任意 `evolve=true` 的觉醒卡提供对局中式神实体的小卡预览与 PNG 导出。视觉参考 `BWPro/gui_ref/20261017055050_38_3_对战.jpg` 中双方八位式神的小卡。

本功能是来源卡的**独立临时预览器**：不新增卡牌类型、不新建对局实体条目、不写回来源卡 yaml，也不实现 BWPro 的「当前形态优先，其次基础/觉醒卡图」自动选材逻辑。BWPro 后续可自行调用纯渲染入口并传入已选定的来源卡和对局状态。

## 渲染架构

新增 `bwpdiy/render/entity.py`，提供独立纯 PIL 入口 `render_entity(card, state, assets_dir, layout=None, crop=True, info=None)`。普通卡牌的 `render_card`、schema、项目存储和版本归组保持不变。

- `card` 提供卡图、卡图偏移/旋转、默认等级与默认勾玉颜色；卡名仅用于导出文件名。
- `state` 字段为 `level`、`level_color`、`power`、`health`、`combat_power`、`shield`、`art_scale`。
- 框体原生尺寸为 **64×96px**（约 2:3），由程序绘制圆角矩形、多层描边和轻微底色，不使用截图抠图，也不缩放到普通卡牌的 512px 高度。
- GUI 可放大预览，但渲染和导出始终使用原生像素；最终按整体最紧透明边界裁剪，探出框体的组件可能使导出尺寸略大于 64×96。
- 合成顺序：卡图 → 框体 → 正下方等级勾玉 → 左下力量、右下生命 → 力量上方战力/乏力、生命上方护甲/破甲。
- 不绘制卡名、描述、稀有度、派系、脚注、觉醒星或协战双框。

复用现有卡图安全加载与变换、数字字体与逐字拼接、六色勾玉，以及战力/乏力/护甲/破甲素材。实体渲染不借普通卡牌 `_STAT_MATRIX` 伪造类型；需要的共享底层绘制能力以小型 helper 复用，避免把临时对局状态耦合进普通卡牌分派。

对局卡图的偏移与旋转始终锚定来源卡 `artwork.images[0]`；缩放不继承来源卡，而由对局专用 `art_scale` 直接替换来源卡 `scale`。`art_scale` 沿用现有卡图缩放口径，以**原画尺寸**为基准进行 cover 缩放，而不是相对来源卡缩放再乘倍率。实现时按普通卡面的 512 合成坐标继承偏移，再等比映射到小卡内窗，避免把 512 画布偏移直接当成 64px 小卡偏移。

## 数值与默认值

- `power`、`health`：非负整数，0 也绘制，不带正负号。
- `combat_power`：整数；正值使用战力图标，负值使用乏力图标并绘制绝对值，0 不绘制该组件。
- `shield`：整数；正值使用护甲图标，负值使用破甲图标并绘制绝对值，0 不绘制该组件。
- 四个数值默认取 0；来源卡已有非负 `power`/`health` 时可用作初值，觉醒卡的 `power+`/`health+` 不当作实体身材。
- `level` 为 1/2/3，默认取来源卡有效等级，否则为 1。
- `level_color` 使用现有六色 yellow/cyan/purple/red/blue/brown，默认取来源卡有效颜色，否则 yellow。
- `art_scale` 为有限正数，默认 1.0；沿用现有卡图缩放安全上限。
- 首版临时状态不提供数值变色；力量、生命和修正数值均为现有白色数字。

## Web API 与交互

新增只读 `POST /api/entity-preview`，请求包含当前来源 `card`、临时 `state`，布局预览时可另带 `layout`。响应为 PNG，并复用现有预览缓存、响应头坐标信息和前端 Blob 下载方式。接口不创建项目文件。

服务端校验来源资格、字段类型与取值范围；布尔值不冒充整数。卡图继续使用现有基准目录约束、路径越界拒绝和像素安全上限。非法输入返回明确中文错误，前端保留上一张有效预览并显示错误。

在卡牌库选中符合条件的卡时显示「对局式神」入口：

- 进入后，中央改为对局小卡预览，右侧仅显示等级、勾玉颜色、对局缩放和四个数值输入。
- 输入变化实时刷新；提供「返回卡面」和「导出对局卡」，默认文件名 `<卡名>_对局.png`。
- 来源卡的卡图偏移与旋转原样使用；临时预览器提供独立 `art_scale`（相对原画尺寸），不提供独立偏移或旋转。
- 切换来源卡、返回卡面或离开卡牌库后丢弃临时状态，不触发来源卡「未保存」标记。

## 布局

`assets/layout.json` 与包内 `bwpdiy/render/default_layout.json` 新增独立「对局式神」段；旧用户布局缺段时从包内默认补齐，不覆盖已有配置。

全局布局设置新增「对局式神」页，提供样卡预览及以下参数：

- 力量、生命、战力/乏力、护甲/破甲各自的图标位置、图标尺寸、数字偏移和字号；共用数字描边口径。
- 等级底座位置、底座尺寸、勾玉相对底座偏移和勾玉尺寸。
- 修正组件使用同一字段的正负两种图标，位置一致，仅按数值符号切换素材。

该段不参与普通六卡牌类型的跨类型样式同步；本功能无持久实体条目，因此不提供单卡布局覆盖。此次出厂布局变更按项目约定在 1.7.0 changelog 首条加粗提示用户可能需要重新调整本地配置。

## 测试与验收

- 渲染测试：64×96 框体、紧致导出、卡图变换、等级六色、力量/生命 0 值显示。
- 数值测试：`combat_power` 正/负/0 分别对应战力/乏力/隐藏，`shield` 正/负/0 分别对应护甲/破甲/隐藏，负值不画负号。
- API 测试：三类合格来源、普通非觉醒卡拒绝、非法数值与颜色拒绝、预览 PNG 和响应坐标、卡图路径安全。
- 前端测试：入口显隐、四项输入与预览刷新、返回不保存、导出文件名、布局页控件。
- 运行既有全量 pytest 与 JS 语法检查；用浏览器自动化实际走一遍进入预览、修改数值、返回和导出，并人工查看一张 64px 小卡的清晰度。
- 更新术语表、AGENTS 架构/资源说明、设计文档与 changelog；版本保持 1.7.0，本任务不自动打包发布。
