# 机制框默认宽度调整设计

## 目标

内置回退的三类机制框当前默认宽 324px：288px 文本区加左右各 18px。保留默认字号下每行约 12 个汉字，同时缩窄两侧留白，避免框体视觉过宽。

## 方案

- 三类机制框统一采用 312px 默认宽度：文本区仍为 288px，左右 `text_x` 均为 12px。
- 同步修改 `bwpdiy/render/mech.py` 的内置回退、`assets/layout.json` 与 `bwpdiy/render/default_layout.json` 的「机制」段。
- 渲染参数由像素 `width` 改为 `chars_per_line`：显式指定每行汉字数，缺省按布局文本宽（出厂默认 12）；不再接受像素宽度。
- `font_scale` 同步缩放文字、文本区、框宽与横向偏移，缩放前后保持相同每行字数；竖直留白与角标尺寸逻辑不变。
- 机制 yaml 增加可选 `chars_per_line` 正整数字段，右侧提供「每行字数」输入框；新建及旧数据缺省均为 12，预览与导出使用当前条目值。
- 不自动覆盖已有正式版用户目录中的 `.bwpdiy/layout.json`；既有本地布局继续优先生效。

## 验证

- 更新机制渲染测试：默认 12 个汉字不换行，13 个汉字换行；默认框宽为 312px，文本区为 288px、左缘为 12px。
- 检查三类框的显式每行字数、原生最小框宽、字体倍率保持字数、参数异常，以及条目保存/预览和前端校验，运行全量测试。
- 后续若发布该出厂布局变更，更新说明首条按项目约定加粗提示用户可能需要重新调整本地布局。
