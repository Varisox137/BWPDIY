BWPDIY 使用说明

基本流程

左栏新建项目与卡牌（默认新建式神；非式神卡的「所属式神」可关联同项目式神）→ 右栏编辑卡牌内容、上传卡图 → 中央实时预览 → 「保存」写盘；「导出卡图」把当前卡牌（含未保存修改）下载为 PNG 图片（默认按卡名命名）。卡图按 id（留空则按卡名）命名落盘。连续 2 小时无操作时程序会自动停止（防占用），重新启动即可。

描述文本自适应

描述自动换行、每行水平居中、整体竖直居中；排不下时先微调居中点、再自动逐级缩小字号；遇左下/右下角标自动避让，文字不会压到数值。

关键字高亮

描述中用双英文方括号 [[关键字]] 标记，显示为牌框对应的异色（括号本身不绘制）；从左往右匹配，未配对的括号与单个 [ ] 一样按普通文本显示。

内嵌小图标

描述中输入 #xx（两位拼音首字母代码）插入行内小图标，与相邻文字间自动留八分之一宽空格；图标大小随字号缩放（布局设置中可调相对大小）。可用代码：
#ll 力量#sm 生命#hj 护甲#pj 破甲
#nl 能量#nj 耐久#zl 战力#fl 乏力
#hl 红莲#cy 苍叶#ql 青岚#zy 紫岩

卡图定位

上传卡图后可调偏移 X/Y（正值=图像右/下移）、缩放、旋转（正角度=顺时针）；也可直接在预览画布上鼠标操作：左键拖拽=移动、滚轮=缩放、按住右键+滚轮=旋转（3°/档；主预览与式神头像预览均支持，与数值框双向同步），拖拽中即可实时查看精确预览，松开后强制最终刷新。「撤回上次修改/撤回全部修改」按钮可回退未保存的编辑（鼠标操作与输入框都生效，连续拖拽/滚轮按一次修改计）。平出画面的区域会留透明，可放大缩放避免露底。改动需「保存」后写盘。式神卡的卡图四项右侧另有并排的「头像」设置（同四参数），用于协战双式神框中该式神的头像裁剪，预览框以 2 倍大小实时显示在卡图预览下方；「头像框」勾选控制头像预览/导出头像是否绘制斜方框与派系标（不勾选=仅菱形裁剪的裸头像），「导出头像」按当前预览直接下载 PNG。

机制描述框

左栏「机制」为全局共享列表（不随项目切换，所有项目可复用），用于制作灵咒/关键字/加护蚀印等机制说明图：新建时选框类型（默认关键字）、填名称与描述即可，框高按内容行数自动伸缩（最少 2 行：名称+空行；名称与描述之间空一行，超过 5 行时框体按行高拼接加长，不缩小字号）。右栏「每行字数」可逐机制调整（默认 12），框宽随字数自动适配。描述逐行左对齐，同样支持 [[关键字]] 高亮与 #xx 内嵌小图标（唯一/瞬发等标记直接写进描述即可）；加护蚀印框可选「加护/蚀印」圆形角标（名称自动右移避让）。「导出描述框」把当前机制（含未保存修改）下载为 PNG。

框品

支持常规/琉璃/墨染/百炼四种牌框配色（协战仅常规），文字与稀有度配色随框品自动切换。卡牌库与布局设置均在中央预览上方以四个按钮切换；全部元素和文本区按卡牌类型、框品独立调整，单卡布局叠加在该卡实际框品的全局配置上。正式版布局保存于用户目录 .bwpdiy/layout.json，开发版为项目 assets/layout.json。

协战双式神框

协战卡可勾选「双式神框」，在牌框左上外侧渲染双菱形头像框；头像自动取所属式神卡的卡图（式神缺卡图则该槽位留空菱形），派系小标随式神派系。

扩展选项

顶栏「扩展选项」可自行启用：手动调整布局——开放「全局布局设置」页，按卡牌类型与框品独立微调各元素位置/字号/文本区，第七类「机制」页三画布（灵咒/关键字/加护蚀印）同屏调整机制描述框：字号类三类共用，文本区域（偏移/宽度）各框独立，浅绿框按实际文本块标示；并在卡牌库右栏开放「调整单卡元素布局」，对当前卡单独覆盖布局（只把与全局不同的项写进该卡，还原/保存互不影响全局）；标记扩展——稀有度下拉开放 N 与「无」（衍生牌）；等级下拉开放 0（无等级）与勾玉六色（黄/青/紫/红/蓝/棕）；式神开放派系样式（1-3，默认 2）；各数值旁开放变色（白=常态/红=debuff或受伤/绿=buff/紫=中毒，正负号跟随变色）。取消勾选只隐藏控件，已写入卡牌的颜色/样式不回退。
