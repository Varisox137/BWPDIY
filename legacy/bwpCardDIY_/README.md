## bwpCardDIY

本项目旨在辅助使用者进行网易手游《阴阳师：百闻牌》中的卡牌DIY。



##### 开发记录

暂时不支持gui程序。

暂时不支持选择牌框种类。

暂时不支持选择卡图的蒙版定位。

暂时不支持选择卡牌等级的图案颜色。

暂时不支持自定义字体/文字颜色。



#### 卡牌说明

对于需要DIY的卡牌，根据其卡牌类型，所需要的参数有所不同。可选的卡牌类型有：式神、战斗、法术、形态、幻境。所有类型的卡牌图片大小一致，默认为307x546px。

以下参数中，用括号（）表示该参数的默认值，如：卡牌参数X（“default_param”）。

通用参数：名称（“名称”）、描述文本（“描述文本”）、卡图（“./card_image.png”）

式神参数：派系（“红莲”）、力量（1）、生命（1）

卡牌（战斗、法术、形态、幻境）通用参数：等级（1）、是否觉醒（False）、稀有度（“R”）、从属式神（“从属式神”）、特殊类型（None）

战斗牌独有参数：力量加成（0）、护甲加成（0）

法术觉醒牌独有参数：永久力量加成（0）、永久生命加成（0）

形态牌独有参数：力量（1）、生命（1）

幻境牌独有参数：耐久（1）



#### 程序运作

1、参数解析

程序首先默认读取同目录下的card_config.json配置文件，获取要制作图片的相应卡牌参数。通过命令行运行脚本时，解析到的参数会覆盖配置文件中的同名参数。通过gui运行时，下拉框选择或文本框填写的内容若非空，将覆盖配置文件的相应参数。

2、卡图蒙版与牌框

根据不同卡牌类型，获取相应的卡牌边框和卡图蒙版（式神与形态牌一致）。从本地路径读取目标卡图。将目标图片进行一定的平移、旋转、缩放，然后根据蒙版生成遮罩后的卡图。

根据所选择的卡牌类型和牌框，将牌框覆盖在卡图上，形成基本的卡牌外观。

3、图案添加

对于式神卡牌，如果派系参数不为“无相”，则在卡图与文本区域分界的中央添加相应的派系图案。

对于非式神卡牌，在左上角相应位置添加指定颜色的等级图案。如卡牌是否觉醒参数为True，则先添加觉醒牌图案，再覆盖添加等级图案。

对于非式神卡牌，在卡牌的名称区域两侧分别添加相应的稀有度图案。相同稀有度的图案样式在所选择的牌框风格不同的情况下也会不同。

对于式神或形态牌，在卡牌左下角添加力量图案，在右下角添加生命图案。

对于幻境牌，在卡牌右下角添加耐久图案。

对于战斗牌、法术觉醒牌，如果某个独有参数非零，则在相应位置添加相应图案。战斗牌力量加成：左下角，力量增加或降低图案。战斗牌护甲加成：右下角，护甲或破甲图案。法术觉醒牌：左下角为力量增加图案，右下角为生命图案。

4、图案数字添加

根据添加在卡牌左下角/右下角的图案，由非零值的相应参数生成数字并添加在相应图案上。其中战斗牌参数、法术觉醒牌参数的数值前带有正负号，而其余添加到图案上的参数值没有符号。

5、名称和类型注释添加

在文本区域的名称区域，居中添加卡牌名称。

在卡牌底部的注释区域，根据类型、从属式神、特殊类型，合成相应文本并添加。例如，对式神卡牌“妖刀姬”，文本为“妖刀姬-式神”，其战斗牌（从属式神属性为“妖刀姬”）的注释文本为“妖刀姬-战斗”。对于自身额外具有特殊卡牌类型的式神，例如御馔津的“驱魔符/驱魔箭”，其应当具有参数特殊类型为“符咒”，从而合成的注释文本为“御馔津-法术/符咒”。

6、描述文本的解析和添加

描述文本中可能出现关键词或小图标，前者与常规文本配色不同，后者以非文本形式嵌入卡牌的描述区域。对于字符串类型的描述文本参数，约定以方括号标记关键词配色，以井号标记小图标。小图标使用相应标记的首字母缩写，目前可能的小图标有：力量、生命、护甲、破甲、能量、耐久、战力、乏力、赏金。以上描述文本的解析若发现格式不合法，则重置为空字符串。

例如，青坊主“佛印”：“[瞬发]\n为双方牌手恢复4#sm。”

根据之前已经添加的左右下角图案和数字，确定描述文本可以放置的空间范围，使文本不与卡牌图案发生重叠。然后对字体从大到小尝试放置描述文本：先根据字号计算最大文本行数，从一行开始逐步尝试，在文本没有手动换行的情况下，在每行相应位置在可放置空间内居中排列尽可能多的文字，如果无法不重叠不超出区域放置所有文本则增加行数，行数已满则减小字体重试，直到能够放置所有文本。解析的文本中常规文字和关键词部分的颜色依据之前选择的牌框而有所不同。同时在此过程中，解析到的小图标在放置占位时同样根据递减的字号而相应缩小。
