# BWPDIY 1.8.0 对局预览与状态组件设计

日期：2026-11-01
状态：已与用户逐项确认，待书面审阅

## 目标与范围

新增独立「对局预览」页，集中提供大卡与对局式神小卡的临时状态预览和导出；新增小卡能量/倒计时/气绝倒计时、大卡爆能组件，并按 `assets/ref/` 校准白、红、绿、紫、黄五种数字渐变。所有对局配置只影响当前预览与导出，不写回卡牌 YAML。

本批次版本统一为 1.8.0；实现、测试和文档收尾后不自行打包发布，等待用户明确要求。

## 渲染状态契约

### 对局式神小卡

`render_entity(card, state, ...)` 的 `state` 增加：

- `energy: int | None`：非负整数，0 也绘制；非空时右上角使用能量图标，数字自动使用黄色。
- `countdown: int | None`：正整数；非空时右上角使用倒计时图标，数字白色。
- `energy` 与 `countdown` 至多一个非空，二者同时非空则抛出 `ValueError`。
- `defeated_countdown: int | "infinity" | None`：非空即气绝；非负整数显示普通气绝倒计时（含 0，供复活过渡帧），`"infinity"` 表示永久气绝并绘制白色 `∞`。其他字符串、布尔值和负数均拒绝。

气绝时：

- 仅灰化小卡底框与卡图，已有等级、能量和数值角标保持原色。
- 隐藏右上角倒计时；右上角能量继续显示，不灰化，数字仍为黄色。
- 中央气绝倒计时最后绘制，位于等级、能量和全部数值角标之上；数字和 `∞` 均为白色并保留描边。
- 既有 0 级规则不变：只绘制底框与卡图，不绘制任何等级、数值或本轮新增组件。

未气绝的小卡不显示中央气绝组件。普通右上角倒计时和气绝倒计时不会同时出现，能量可与气绝倒计时同时出现。

### 大卡爆能

`render_card` 从卡牌渲染字典读取可选 `burst`：

- 带符号整数，正数显示 `+N`，负数显示 `-N`，0 或缺省不绘制组件。
- 使用能量大图标和白色数字，正负号沿用现有贴图与数字整体居中规则。
- `burst` 是渲染专用临时字段，不加入 store 卡牌 schema，不由 GUI 保存；BWPro 在调用渲染入口时传入。
- 图标以当前类型/框品的等级底座布局坐标为锚点，即使卡牌无等级也仍可使用该布局锚点。布局通过相对偏移保证组件位于等级标正下方。

所有新组件参与既有工作边界、紧致裁剪和 `width/height` 原生重绘；不得通过缩放默认成品实现目标尺寸。

## 布局配置

三份出厂/内置配置保持同步，旧用户布局缺新元素时从包内默认深补全，不覆盖已有配置。

- 六种卡牌类型及其框品增加 `elements.burst`，包含 `kind: burst`、相对等级底座的 `offset`、`icon_size`、`num_offset`、`font_size`、`stroke_width`、加/减号尺寸及符号和整体偏移。各类型、框品继续完全解耦。
- 「对局式神」增加 `elements.right_top`：右上角能量/倒计时共用 `pos`、`icon_size`、`num_offset`、`font_size`、`stroke_width`。
- 「对局式神」增加 `elements.defeated`：中央气绝倒计时独立配置同类参数；`∞` 复用该组件的字号、描边、数字偏移与中心对齐规则。
- 新元素全部计入可见边界，允许越出 96×144 底框；布局页可拖拽并编辑参数。
- 全局布局样卡增加爆能数值、右上角组件选择/数值、气绝与永久气绝开关，以便直接调整新组件；这些样例值不写盘、不计未保存。

出厂布局变化按项目约定在 1.8.0 更新说明首条加粗提醒用户重新检查本地布局。

## 数字渐变

根据 `assets/ref/{白字,红字,绿字,紫字,黄字}.png` 的数字内部像素重新校准顶部到底部渐变，不从描边或背景取色。保留当前黑色描边和按整串数字墨迹施加渐变的方式。

- 白色也成为显式渐变，普通数字与正负号默认使用该配色。
- 红、绿、紫更新后仍用于既有大卡/小卡数值及正负号。
- 黄色只由能量组件内部指定，不加入普通数字颜色下拉，也不允许通过既有 `<field>_color` 选择。
- 倒计时、气绝倒计时、永久气绝符号和爆能固定白色。

## 对局预览页

顶栏顺序为「卡牌库 / 对局预览 / 全局布局设置」。进入对局预览前必须在卡牌库选中卡牌条目；未选卡或正在编辑机制时显示提示，不建立预览状态。

左侧只选择样式，可选范围以来源卡为准：

- 主要式神、衍生物式神：仅式神小卡。
- 普通非式神卡：仅大卡。
- 形态牌、任意觉醒牌：大卡与式神小卡均可切换。

中央显示实时预览和「导出」按钮，导出当前样式及全部临时状态。右侧配置：

- 大卡：临时等级 0–3、六色勾玉、现有数值的白/红/绿/紫颜色、带符号爆能数值。
- 小卡：现有等级、六色勾玉、对局缩放、力量/生命/战力/护甲及其颜色；右上角「无/能量/倒计时」下拉和对应数值；「气绝」勾选、气绝倒计时及「永久」勾选。永久气绝时停用数字输入。

预览初始值取当前选中卡及卡牌库尚未保存的表单内容；已有 YAML 的颜色字段只作为初始值。对局页全部状态独立、临时、不写盘、不置脏，也不进入卡牌撤回栈。离开后不保留临时状态；返回卡牌库时仍选中该条目，并保留此前未保存的卡牌编辑。

复用现有项目大卡预览和 `/api/entity-preview`，不新增本地写接口。大卡通过表单副本注入临时字段，小卡通过 `state` 传参；卡图路径、资源根和数值限幅沿用现有安全校验。

## 旧界面迁移与布局页

- 卡牌库删除对局小卡常驻图片、对局参数、勾玉换色和数字换色控件；保留大卡预览、主要式神头像预览及其已有编辑功能。
- 卡牌库不再提供颜色字段写入入口；已有字段仍由渲染库兼容读取。
- 新增 `editor-battle.js` 承担对局页状态和交互，避免继续扩张卡牌编辑脚本；按现有经典脚本依赖顺序加载，不引入框架或构建步骤。
- 全局布局页增加上述新元素及样例控制；对局式神布局继续独立，不参与六类型传播。

## 错误处理与安全

- 状态字段严格要求整数/指定字符串，布尔值不得冒充整数；互斥、取值范围和位数在渲染边界校验。
- 新组件沿用坐标、尺寸、字号、工作画布和像素预算上限；永久气绝不以任意大整数模拟。
- 新预览不写盘，不增加路径输入；现有卡图路径约束、跨站写校验、请求防逆序和导出文件名清理不变。
- 渲染失败保留上一张有效预览并显示中文错误；切卡或离开页面后旧响应不得覆盖新页面。
