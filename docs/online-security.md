# 在线本地版安全说明

## 边界

在线服务发布 `prototype/pyodide/` 中的浏览器应用。渲染在用户浏览器的 Web Worker 内完成；服务器不提供渲染、上传、项目读写或账户 API。唯一动态数据接口是需提取码的只读日志管理。正式版编辑器及其 8630/8631 端口不得经花生壳或反向代理公开。

服务器只监听 `127.0.0.1:8640`，由花生壳或本机反向代理回连。公网 HTTPS 必须在可信边缘终止。

## 服务端防护

- 仅允许 `/`、明确列出的程序文件、`/runtime.json`、`/runtime-chunks/<序号>` 与日志运维页；其他地址、目录、编码路径穿越、旧 `/prototype/pyodide/` 路径、整包 `/runtime.zip` 和 `/api/render` 均为 404。GET/HEAD 使用同一路由，写方法被拒绝。
- 运行时 ZIP 在启动时压缩并缓存不可变字节，更新后重启服务才重建；浏览器按清单顺序下载 2 MiB 分包，每包独立重试，流式读取时每 100 ms 至多更新一次包内 KiB 进度并显示总 MiB/百分比；不支持流式响应时回退为逐包进度。进度只更新预览区，不写入页面日志。
- 正常资源默认全服务限流为 120 请求/分钟、30 次突发，超限返回 429；异常路径与不支持的方法使用独立配额，同一来源 10 秒内达到 8 次后冷却 300 秒。异常请求不消耗正常资源配额，冷却也不拦截正常静态资源。可用 `--request-rate`、`--request-burst`、`--abuse-limit`、`--abuse-window`、`--abuse-cooldown` 调整。
- 同时最多处理 8 个连接，请求头读取超时 20 秒、响应传输超时 120 秒，等待队列 32。运行时包和桥接下载最多尝试 3 次；可用 `--max-connections` 调整。
- 默认仅以 socket 对端为限制来源，忽略 XFF 等可伪造请求头。花生壳免费版无法提供可信来源时，所有回连请求共享异常地址配额，但正常资源不受异常冷却影响。只有可信代理会覆盖写入单个真实 IP 时才可用 `--client-ip-header` 启用按来源隔离；多值、无效或缺失头回退 socket 对端，不得让浏览器自行上报公网 IP 作为安全凭证。
- 响应包含 CSP、`nosniff`、禁止嵌入、无来源引用、同源 opener/resource 策略及设备权限禁用。CSP 仅开放同源和固定版本 jsDelivr Pyodide 资源。
- 浏览器或隧道提前断开的 BrokenPipe/连接重置只记录一条简洁日志；未知程序异常仍保留完整堆栈。访问日志只记录方法、规范路径与状态码，不记录查询参数、Authorization 或提取码。

## 日志运维

- 每次启动写一份 UTF-8 运行日志，保留最近 10 份并删除超过 7 天的旧日志；launcher 日志位于同一 `logs/` 目录。
- `/log-admin/` 提供列表、开头 512 KiB 预览和完整下载，不提供删除、修改或执行操作。
- 提取码为 16 位十六进制随机值，每 10 分钟轮换；当前值只在交互终端显示，或写入权限受限的 `logs/.log-access-token`。不会写入应用或 launcher 日志。
- API 仅接受 `Authorization: Bearer <提取码>`，响应 `Cache-Control: no-store`；Service Worker 不接管运维页和日志 API。同一回连地址 60 秒内连续 5 次鉴权失败会暂时拒绝继续尝试。
- 文件名和解析后的真实父目录双重校验，非日志、路径穿越和目录外链接均不可读。GUI 提取码仅存当前标签页内存，不写 localStorage。

## 用户文件与浏览器数据

- 文件选择、卡图字节、草稿、布局均不发送给服务器。界面仅接受 PNG/JPEG/WebP 且文件不超过 64 MiB；Worker 在初始化前再次限制字节数，并只允许内部 `artwork.<ext>` 文件名，恶意草稿不能通过 `../` 覆盖虚拟文件系统其他文件。
- Pillow 解码前检查原图不超过 6400 万像素，缩放中间图、最终画布与机制框另有尺寸上限。无效图片只产生当前浏览器内的渲染错误。
- 草稿备份最多 100 MiB，仅存当前源下的 IndexedDB；程序与素材存 Cache Storage。清除资源缓存不删除草稿或布局。
- Service Worker 只处理静态白名单和固定版本 Pyodide CDN，使用不带查询参数的规范缓存键。更新资源必须递增缓存版本。
- 页面使用 `textContent` 和表单值展示用户内容，不将卡名、描述、机制或日志文本注入 HTML，也不使用 `eval`。
- 互动教程只使用本地快照和范例内容；教程期间不写入 IndexedDB，退出恢复，保留作品时才保存。localStorage 不含作品内容或提取码，仅保存低负载和教程完成偏好。

## 保留风险与部署要求

- 公开静态资源不具保密性；限流不能彻底防止带宽耗尽或分布式攻击。应同时在花生壳/反向代理配置流量、并发和访问控制，并监控 429 与异常日志。
- 日志可能包含内部路径和错误细节，下载后应妥善保管。提取码泄露时等待轮换或重启服务，并删除不再需要的下载副本。
- Pyodide 当前依赖固定版本 jsDelivr，属于第三方供应链与可用性边界；长期部署宜自托管同版本文件。运行时 ZIP 必须来自受信任部署目录。
- 浏览器本地数据可能被用户清理、隐私模式或系统回收；持久存储授权不是备份，重要作品仍应导出 PNG 和草稿备份。
- 修改 CSP、Worker、缓存白名单或日志接口后，必须重新验证首次渲染、上传、二次加载、离线重载及日志鉴权。

## 本次验证

- `tests/test_pyodide_prototype.py` 覆盖资源包复用、安全头、路径穿越、正常/异常独立限流、可信来源开关、冷却恢复与状态上限、缓存变体、恶意卡图、响应超时、下载重试、包内流式/回退字节进度和断连处理。
- `tests/test_online_log_admin.py` 覆盖提取码、失败限流、文件名边界、列表、预览、下载、只读方法和响应禁缓存。
- 真实 Edge 验证空白默认卡自动渲染、运行时分包 64 KiB 流式读取、12 包缓存完成及服务停止后的离线重载；包内 KiB/总 MiB/百分比进度由 Node 流式与回退测试覆盖。另已验证运维页错误鉴权、列表、预览和完整下载。
- 真实 HTTP 验证异常路径先返回 404、达到阈值后返回 429，伪造 XFF 不绕过共享限制；冷却期间正常首页、Worker 和运行时清单仍为 200，POST 返回 405 且不消耗正常配额。
