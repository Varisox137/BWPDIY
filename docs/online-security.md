# 在线本地版安全说明

## 边界

在线服务只发布 `prototype/pyodide/` 中的浏览器应用。渲染在用户浏览器的 Web Worker 内完成；服务器不提供渲染、上传、项目读写或账户 API。正式版编辑器及其 8630/8631 端口不得经花生壳或反向代理公开。

服务器仍只监听 `127.0.0.1:8640`，由花生壳或本机反向代理回连。公网 HTTPS 必须在可信边缘终止。

## 服务端防护

- 仅允许 `/`、八个明确列出的程序文件与 `/runtime.zip`；其他地址、目录、编码路径穿越、旧 `/prototype/pyodide/` 路径和 `/api/render` 均为 404。GET/HEAD 使用同一路由，其他写方法由 HTTP 服务器拒绝。
- `runtime.zip` 在启动时压缩并缓存不可变字节，更新后重启服务才重建，避免每次请求重复消耗 CPU。
- 默认全服务限流为 120 请求/分钟、30 次突发，超限返回 429；同时最多处理 8 个连接，连接读写超时 20 秒，等待队列 32。可用 `--request-rate`、`--request-burst`、`--max-connections` 调整。
- 限流是进程级保护，不根据可伪造的 XFF 伪造按用户隔离。花生壳后的真实客户端地址不作为安全凭证；公网流量、并发和 WebSocket 限制仍应以边缘配置为准。
- 响应包含 CSP、`nosniff`、禁止嵌入、无来源引用、同源 opener/resource 策略及设备权限禁用。CSP 仅开放同源和固定版本 jsDelivr Pyodide 资源，禁止对象、表单提交与 base 标签。

## 用户文件与浏览器数据

- 文件选择、卡图字节、草稿、布局均不发送给服务器。界面仅接受 PNG/JPEG/WebP 扩展名且文件不超过 64 MiB；Worker 在初始化前再次限制字节数，并只允许内部 `artwork.<ext>` 文件名，恶意草稿不能通过 `../` 覆盖虚拟文件系统其他文件。
- Pillow 解码前检查原图不超过 6400 万像素，缩放中间图、最终画布与机制框另有尺寸上限。无效图片只产生当前浏览器内的渲染错误。
- 草稿备份最多 100 MiB，仅存当前源下的 IndexedDB；程序与素材存 Cache Storage。清除资源缓存不删除草稿或布局。
- Service Worker 只处理静态白名单和固定版本 Pyodide CDN，使用不带查询参数的规范缓存键，未知地址不被缓存接管。更新资源必须递增缓存版本。
- 页面使用 `textContent` 和表单值展示用户内容，不将卡名、描述或机制文本注入 HTML，也不使用 `eval`。

## 保留风险与部署要求

- 公开静态资源不具保密性；限流不能彻底防止带宽耗尽或分布式攻击。应同时在花生壳/反向代理配置流量、并发和访问控制，并监控 429 与异常日志。
- Pyodide 当前依赖固定版本 jsDelivr，属于第三方供应链与可用性边界；正式长期部署宜自托管同版本文件。运行时 ZIP 必须来自受信任部署目录，服务账户只需读取发布文件，不应拥有系统其他目录权限。
- 浏览器本地数据可能被用户清理、隐私模式或系统回收；持久存储授权不是备份，重要作品仍应导出 PNG 和草稿备份。
- 安全头不能替代浏览器兼容测试。修改 CSP、Worker 或缓存白名单后，必须重新验证首次渲染、上传、二次加载与离线重载。

## 本次验证

- `tests/test_pyodide_prototype.py` 覆盖资源包复用、根路径、HEAD、安全头、路径穿越、旧路径、未知 API、全局限流、缓存查询变体和恶意卡图路径/大小。
- 真实 Edge 浏览器验证 CSP 下自动渲染、本地卡图、在线二次加载与完全离线重载；移动端双指只改变卡图，不改变页面比例。
- 异常路径均为 404，POST 被拒绝；40 个并行请求出现 429，等待限流恢复后正常请求仍为 200。
