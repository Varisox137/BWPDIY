# 对局式神布局预览调整设计

## 目标

- 全局布局设置中的对局式神预览按原生 96×144 的 3 倍显示，PNG 和布局坐标仍使用原生尺寸。
- 渲染时允许等级标、数值标等元素超出 96×144 框体；按框体与所有实际可见元素的联合 alpha 边界紧致裁剪，不提前裁掉框外内容。
- 左侧元素在等级、卡图内窗之后固定按力量、生命、战力、护甲排列。
- 保持等级标黄、青、紫、红、蓝、棕六色支持，并补充布局样卡对非默认颜色的覆盖。

## 实现

`render_entity` 根据框体、启用的元素及当前状态计算工作画布范围，将框体和元素统一平移到工作画布后按原顺序渲染，最后按 alpha>10 的联合边界裁剪；`crop_origin` 继续报告原 96×144 坐标系中的裁剪原点。正常未越界渲染保持原有像素结果，导出与布局预览共用同一链路。

前端仅把布局页 CSS 放大倍率改为 3，并为对局式神元素使用显式顺序；鼠标坐标继续按实际显示比例换算。布局样卡使用非默认勾玉颜色，以实际预览验证颜色链路。

## 验证

- 渲染测试：默认尺寸与裁剪不变；等级标越出底边时完整保留且裁剪原点正确；六色资源调用保持正确。
- 前端测试：3 倍显示、紧致图片尺寸、鼠标反算、元素顺序与样卡颜色。
- 运行全量 pytest 与 JavaScript 语法检查，保留用户尚未提交的 `assets/layout.json` 调整。
