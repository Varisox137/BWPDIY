# 对局式神右上组件独立布局与永久气绝字形调整

日期：2026-11-03
状态：方案已由用户确认

## 目标

全局布局的「对局式神」页中，能量与普通倒计时不再共用 `right_top` 元素；两者均可独立调整图标与数字。样例选择从下拉框改为互斥勾选框。永久气绝继续使用 `∞`，但收窄并增高自绘轮廓。

## 布局与兼容

- `elements.energy` 与 `elements.countdown` 均为 `kind: counter`，分别包含 `pos/icon_size/num_offset/font_size/stroke_width`。
- `energy` 仅在 `state.energy` 非空时绘制，数字黄色；`countdown` 仅在未气绝且 `state.countdown` 非空时绘制，数字白色。
- `defeated` 保持独立且最后绘制；0 级仍只绘制底框与卡图。
- 加载旧布局时，若存在 `elements.right_top`，将其参数复制到缺失的 `energy/countdown`，随后移除旧元素；已有新元素不被覆盖。缺新元素时仍从包内默认补齐。
- 对局预览页与 `state` 契约不变；仅全局布局结构和布局编辑器改变。
- 开发版与正式版统一读写 `$HOME/.bwpdiy/layout.json`，包内 `bwpdiy/render/default_layout.json` 仅作缺省回退；删除不再作为开发版配置使用的 `assets/layout.json`。

## 布局编辑器

- 「卡牌内容」中的右上组件下拉框替换为「能量」「倒计时」两个勾选框。
- 勾选其中一个时自动取消另一个；再次取消当前勾选则两者均不显示。
- 两个组件各自保留数值输入；能量允许 0，倒计时从 1 开始。
- 元素列表按「能量」「倒计时」「气绝倒计时」分别显示，各自支持拖拽图标锚点和数字锚点，以及独立右栏参数。
- 样例状态仍不写盘、不计未保存。

## 永久气绝字形

不使用 `∝` 等语义不同的 Unicode 字符，也不依赖字体对 `♾` 的支持。保留 `_render_infinity` 的双环白字黑描边实现，将每个环的宽度由字号 ×0.75 调整为 ×0.55、高度由 ×0.50 调整为 ×0.65；整体更窄、更高，继续参与居中、边界计算与原生尺寸缩放。
